title: "Installing Skills with the Claude Code CLI"
---

```bash
npx skills add anthropics/claude-code --skill frontend-design
```

> **Note:** The article shows a space before `skill` with a single dash (`- skill`), but the correct CLI syntax uses a double dash: `--skill`. This is standard `npx` flag notation.

Once installed, invoke it inside Claude Code with:
```
/frontend-design
```
