title: "Installing the Google Workspace Skill"
---

```bash
# Install
npm install -g @googleworkspace/cli

# Start MCP server with selected APIs
gws mcp -s drive,gmail,calendar,sheets

# Add the skill
npx skills add https://github.com/googleworkspace/cli --skill gws
```

Once installed, invoke it inside Claude Code with:
```
/gws
```

Claude now has direct access to these APIs.
